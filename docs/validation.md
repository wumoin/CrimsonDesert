## 自动定位与五个子开关的离线验证

后续已移除固定 RVA 和固定槽号，增加自动 RTTI / 虚表 / 分派定位，以及五个独立的条件覆盖开关。亲密度和种族是继前三项之后新增的开关，默认均关闭。当前本机 EXE 的文件版本为 `1.0.0.3462`，Steam build 为 `26356046`，SHA256 为：

```text
2c98b00e8922f14ac1937b5ac996956c7b9ca2d0fbcb0049dc0436321a09dd77
```

在单独验证程序中把该文件的节映射到内存，只读取内容，不执行游戏入口或评估函数。当前文件没有标准重定位表，验证映射使用其声明的基址 `0x140000000`。

自动解析成功：

| 类型 | 虚表 RVA | 评估槽 | 评估函数 RVA |
| --- | --- | --- | --- |
| CheckFriendlyLevel | 0x05cff138 | 21 | 0x02440800 |
| IsMarriageable | 0x05cfb8c0 | 21 | 0x024891d0 |
| HasLivingTogether | 0x05cfba30 | 21 | 0x024899e0 |
| CheckAffinityLevel | 0x05cff2a8 | 21 | 0x024415e0 |
| CheckTribe | 0x05cf6b40 | 21 | 0x02420250 |

离线检查通过：缺失 RTTI 时拒绝；关键评估指令模式改变时拒绝；重复兼容虚表时拒绝；移动虚表并把分派槽改为 22 后成功重定位；恢复映像后成功重定位；非游戏宿主拒绝。

初版五条件实现验证过 2,560 种简单映射组合，但当时遗漏了等级成功/失败分支的语义互斥问题，不能据此认定等级覆盖正确。当前已改为保留比较方向，验证范围见下节。通过实际 Win32 INI API 读取中文注释配置的 64 种总开关 / 子开关组合仍通过。验证代码留在仓库外，没有恢复运行时自检或测试工具构建分支。

**这些结果只证明离线定位与配置 / 映射逻辑，不证明运行中的游戏已安装新挂钩，也不证明新增条件覆盖或完整多配偶玩法有效。** 新版构建输出尚未自动替换游戏目录中的插件。

## 示爱 / 求婚分支冲突修正

用户反馈：已尝试示爱，多个 NPC 在可选择求婚后拒绝，并降低好感。检查交互二进制记录发现成功分支使用亲密度 >=3，失败分支使用亲密度 <3；旧覆盖会把二者都变成满足。这是已确认的代码缺陷，但尚未实机确认它是用户所有求婚失败的唯一原因。

修正后离线验证通过：

- 两个等级类型的运算字段、阈值字段和六个比较运算从当前 EXE 自动恢复；字段偏移为 0x1a / 0x1b。
- 亲密度 >=3 成功分支返回满足，亲密度 <3 拒绝分支返回不满足；好感等级的成功 / 失败比较同样保持互斥。
- 两个等级类型、六个运算、七个有符号阈值边界、全部字节原返回值和两种开关状态，共 43,008 个比较用例通过。
- 另外三个条件的 1,536 个结果映射用例通过；64 种总开关 / 子开关配置组合通过；原定位缺失 / 重复候选 / 移位等检查继续通过。

该轮没有启动游戏、执行游戏入口或改写用户存档，也未替换游戏目录中的插件。后续仍需实际确认示爱状态推进、求婚结果和保存重载。

## 历史实机验证

1. 本机当前版本的原始插件源码编译成功。
2. 在游戏进程内通过版本、RTTI、函数指纹和虚函数槽检查，挂钩成功。
3. 带插件到达主菜单，随后载入公开测试存档并进入可操作场景。
4. 原函数在实际游戏流程中产生有效返回：日志最后记录至少 `0/200/0`，依次表示“已有同居对象 / 没有同居对象 / 上下文不可用”；未知返回为 `0`。
5. `Enabled=0` 和 `Enabled=1` 均有有效原函数调用记录。观察到的均为“没有同居对象”，按代码在两种模式下均原样返回。
6. 纯结果映射自检覆盖全部字节值与两种开关状态，共 512 项。

日志摘录见 [runtime-observation.log](../evidence/runtime-observation.log)。此日志可能含启动器或子进程的加载记录，因此 `REFUSED: unsupported game build` 不能单独解释为主游戏挂钩失败。

## 使用的存档与本地状态

公开来源：[wighthawk 的通关存档](https://www.nexusmods.com/crimsondesert/mods/3624?tab=files&file_id=18061)，文件名为 `Full Game Completed (Alternative save after DLC)`，2026-10-30 更新。ZIP SHA256：

```text
0c4c8446fc08f0cedcbcc6d2c54fb1eba4d269b9917ac5139dc9f6aa47b8b904
```

压缩包仅含 `lobby.save` 和 `save.save`，存档 HMAC 和解压校验通过；解压数据为 10,106,767 字节。它含 716 条好感经验为 100 的角色数据，但没有显式的已婚记录。

测试存档导入当前账号的空闲 `slot107`，在游戏中显示为 `SAVE 8` / “归路”。原有手动槽没有被替换。研究目录保留了导入前的本地存档备份；第三方存档及个人备份均未加入本仓库。

**实际副作用：载入通关存档时，Steam 弹出了多项成就解锁提示。成就可能已同步到账号，恢复存档不能保证撤销。**

首次停止实机测试并整理仓库时，游戏进程已不在运行，游戏安装目录中的插件 INI 被恢复为 `Enabled=0`。这是当时的状态记录，后续用户自行启用或更新插件不在此结论内。插件文件未自动卸载，测试用第八槽当时仍保留。
