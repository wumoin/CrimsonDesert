修正后离线验证通过：

- 两个等级类型的运算字段、阈值字段和六个比较运算从当前 EXE 自动恢复；字段偏移为 0x1a / 0x1b。
- 亲密度 >=3 成功分支返回满足，亲密度 <3 拒绝分支返回不满足；好感等级的成功 / 失败比较同样保持互斥。
- 两个等级类型、六个运算、七个有符号阈值边界、全部字节原返回值和两种开关状态，共 43,008 个比较用例通过。
- 另外三个条件的 1,536 个结果映射用例通过；64 种总开关 / 子开关配置组合通过；原定位缺失 / 重复候选 / 移位等检查继续通过。

该轮没有启动游戏、执行游戏入口或改写用户存档，也未替换游戏目录中的插件。后续仍需实际确认示爱状态推进、求婚结果和保存重载。

2. 在游戏进程内通过版本、RTTI、函数指纹和虚函数槽检查，挂钩成功。
