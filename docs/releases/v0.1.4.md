## 本次更新

- **召唤所选伴侣**：管理窗口选中一位已婚伴侣后点击召唤。窗口关闭后发送原版客户端请求，在对应服务端调用中只处理该对象；不改写优先伴侣，也不会因全员开关召唤其他对象。需要新建实例时使用原版同行创建方式。
- **收回所选伴侣**：只收回列表中选中的对象。正在同行时，先通过原版成员退队流程退出同行，再执行原版收回；保留婚姻关系、名字和其他伴侣。收回不受全员开关影响。
- **同行收回修复**：处理原版收回对队员返回 0 却没有移除实例的情况；核对成员、所属玩家和领队后退队，退队失败或仍受阻时停止后续动作。
- **自定义管理热键**：在 INI 的 `[UI]` 分区设置 `ManagerHotkey=F8`，支持 F1～F24、字母、数字、常用命名键及 Ctrl / Alt / Shift 组合，约五秒刷新；窗口标题同步显示热键。
- **INI 自动补全**：启动时依据 ASI 内置的默认配置补齐缺失分区、选项和说明。没有 INI 时自动生成；已有值、注释、自定义热键和伴侣名字保持不变，完整配置不重复改写。
- **切换主角修复**：分别读取当前操控实体的角色编号和主玩家的关系组件，修复德米安实体没有关系组件时被误判为未读档的问题。伴侣仍按主角筛选。
- 保留原有改名、美容选择、中英文界面、全员召唤与读档同行恢复功能。

## 更新与使用

1. 完全退出游戏，用附件 `CohabitationGateExperiment.asi` 替换游戏 `bin64` 中的同名插件。
2. 已有用户保留原 INI；新选项会在下次启动时自动补齐。附件 INI 供首次安装参考，自定义名字初始为空。
3. 默认按 F8 打开管理窗口，选中对象后点击“召唤所选伴侣”或“收回所选伴侣”，窗口会关闭后发送对应请求。需要 `Enabled=1`；原版场景检查仍保留，已在场对象不会强制传送。收回为异步处理，待实例移除后再重新召唤。
4. 例如将已有 `[UI]` 下的 `ManagerHotkey` 改为 `Ctrl+F9`，保存后约五秒生效。缺失或无效热键使用 F8。
5. 首次安装还需要兼容的 x64 ASI Loader。附带的 `winmm.dll` 为 Ultimate ASI Loader v10.0.2，已有兼容加载器可以继续使用。再分发时保留两份第三方许可证。
