# F8 伴侣管理验证

Windows x64，需要与 `build.cmd` 相同的 MSVC 工具链。

```powershell
.\tests\run.cmd
```

构建插件，运行模拟角色、单个临时 INI 和原生对话框回归；验证名字与功能开关共用 INI、保留中文注释、重置只删除目标名字，不加载或操作游戏。测试完成后删除其创建的临时配置。

配置补全回归使用独立临时目录，验证旧配置增加缺失项、缺少分区、缺少或空 INI、重复运行不改写、已有 0/空值/无效值保留、未知分区和名字保留，以及 UTF-8、UTF-8 BOM、UTF-16LE 和系统 ANSI。使用原生 INI API 核对补全后的实际读取结果；只读文件、共享冲突和不可识别内容均保持原文件并清理临时文件。默认值直接从与 ASI 相同的内置资源读取。

窗口绑定回归还会在工作线程接入模拟主窗口，模拟旧窗口销毁但插件未收到通知、窗口隐藏及延迟销毁，验证自动重新绑定、每个窗口正确转发到自己的前任入口，以及旧通知不会清除新窗口状态。

玩家上下文回归直接覆盖 world、manager、session、主玩家和当前操控实体的读取链，包括实机发现的德米安实体没有 contents、关系数据仍属于主玩家的情况。分别核对主玩家和切换后的角色编号，拒绝缺失对象、错误组件 owner 和无效角色编号，避免仅给定一个有效关系组件而漏掉切换主角的问题。

原生名字回归覆盖已缓存长度及 `MAXDWORD` 未缓存长度的 UTF-16 字符串；模拟角色的默认名字采用实机观察到的未缓存格式，验证实际名字赋值和重置，而不只检查插件列表。

双语回归覆盖两种语言的完整文案、默认值、持久化、外部修改重新加载、保存失败回滚及多个窗口同步。管理窗口还检查滚动位置、未保存名字和编辑选区；美容窗口检查原名/自定义名保留、同名区分，以及确定、双击、取消。两个窗口都检查语言下拉框中的默认按钮保护。

热键回归覆盖功能键、字母、数字、命名键别名、组合键及大小写/空格处理；使用模拟按键状态核对主键及修饰键匹配，不向游戏发送输入。临时 INI 验证重新读取后更换绑定、缺失/无效值回退 F8，且不重写原值。管理窗口打开时刷新热键，确认标题变化而选中项、滚动位置、未保存名字和偏好保持不变。

召唤回归分别验证按钮结束模态窗口后才发请求、两种语言的按钮文案、未选中/不可用/忙碌/过期上下文不发请求，以及名字和优先伴侣不改变。模拟请求桥接在独立服务端线程恢复规范布尔值并匹配目标，验证普通请求透传、重复/迟到/错误玩家或角色令牌、发送失败、排队期间切换角色及超时。选中动作测试复用真实的关系读取与作用域选人，即使全员开关和全局偏好指向其他对象，也只调用所选真实已婚对象；只为窗口所选对象使用原版同行创建参数，原版全员及普通创建路径保持原行为。传入 EXE 时额外验证召唤请求入口及字段宽度变化时拒绝。

收回回归沿用同一组请求失败用例，核对服务端收到规范的 false、召唤与收回不能交叉复用旧令牌，以及两个按钮的双语文案、布局、忙碌与失效状态。选中收回验证全员开关及另一位优先伴侣不影响目标，保留原生失败结果，收回作用域不允许创建角色；普通全员召唤/收回均保持原行为。

同行收回准备回归核对只为已验证的伴侣成员调用原版退队，拒绝领队、其他玩家、错误组件及实例；无需退队时不调用，原生退队失败或退队后仍受阻时停止后续收回。退队已清空实例关联时跳过重复调用，不再读取失效对象。真实 EXE 检查包含退队入口、队伍字段恢复，以及退队 ABI 被修改后拒绝、恢复后接受。

可额外传入游戏 EXE 路径，检查真实文件的自动定位和 ABI 不兼容时的拒绝行为：

```powershell
.\tests\run.cmd "D:\gametool\steam\steamapps\common\Crimson Desert\bin64\CrimsonDesert.exe"
```

定位程序只在独立进程内把 EXE 映射为数据，不调用游戏入口或原生函数，不安装挂钩。

检查界面和 F8 的交互可在 x64 Native Tools 命令行运行：

```cmd
cl /nologo /utf-8 /std:c++17 /O2 /W4 /MT /EHsc /DPARTNER_MANAGER_PREVIEW tests\PartnerManagerTests.cpp src\PartnerHotkey.cpp src\UiLanguage.cpp /Fobuild\ /link user32.lib /OUT:build\PartnerManagerPreview.exe
build\PartnerManagerPreview.exe
```

聚焦测试宿主后按 F8 打开窗口，Escape 关闭；关闭宿主结束测试。所有对象和名字仍为模拟数据。以上检查不能代替游戏内显示、读档和召唤的实机验证。

美容窗口可单独预览（先运行一次 `build.cmd` 生成 MinHook 对象）：

```cmd
cl /nologo /utf-8 /std:c++17 /O2 /W4 /MT /EHsc /DPARTNER_BEAUTY_PREVIEW tests\BeautyPickerTests.cpp src\UiLanguage.cpp /Fobuild\ /link user32.lib build\buffer.obj build\hook.obj build\trampoline.obj build\hde64.obj /OUT:build\BeautyPickerPreview.exe
build\BeautyPickerPreview.exe
```
